# Tokenizer Metrics Evaluation

This directory contains scripts and resources for evaluating and visualizing the performance of different tokenizers on various datasets (Code, Indic languages, and NCERT textbooks).

## Directory Structure

*   **`datasets/`**: Contains the source datasets for evaluation.
    *   `code/`: Datasets representing programming languages.
    *   `indic/`: Datasets for Indic languages.
*   **`ncert/`**: Contains NCERT textbook datasets JSONL files.
*   **`tokenizers/`**: Place your tokenizer JSON files here. The `evaluate_tokenizer_metrics.py` script automatically picks up any `.json` file in this directory.
    > Note: The script also automatically includes the tokenizer from `../gptoss_pruning/tokenizer.json` as `our_tokenizer` for easy evaluation of the generated tokenizer.
*   **`graphs/`**: Output directory where visualization plots are saved by `generate_tokenizer_graphs.py`.
*   **`graphs_comparison/`**: Output directory where comparison plots are saved by `generate_comparison_graphs.py`.
*   **`tokenizer_metrics.csv`**: The raw metrics output generated by `evaluate_tokenizer_metrics.py`.

---

## Python Scripts and Usage

### 1. `evaluate_tokenizer_metrics.py`

**Purpose:**  
Calculates metrics (Bytes/Token, Fertility, Speed, etc.) for all tokenizers found in the `tokenizers/` folder against the datasets in `datasets/` and `ncert/`.

**How to Run:**
```bash
python evaluate_tokenizer_metrics.py
```

**Options:**
*   `--limit_lines N`: Limit processed lines per file to `N` for faster testing.
    ```bash
    python evaluate_tokenizer_metrics.py --limit_lines 1000
    ```

**Output:**  
Generates a `tokenizer_metrics.csv` file containing the calculated stats.

---

### 2. `generate_tokenizer_graphs.py`

**Purpose:**  
Generates visualization graphs (bar charts) based on the data in `tokenizer_metrics.csv`.

**How to Run:**
```bash
python generate_tokenizer_graphs.py
```

**Output:**  
Saves `.png` images to the `graphs/` directory.
*   Generates separate plots for each metric (Bytes/Token, Fertility, etc.) across broad categories (Code, Indic, NCERT).
*   Generates summary plots averaging across categories.

**Note on Legends:**  
The legends in the graphs are automatically generated by the script using `seaborn` and `matplotlib`. They are positioned outside the plot area (upper left) to avoid obscuring the data.

---

### 3. `generate_comparison_graphs.py`

**Purpose:**  
Designed to compare specific custom tokenizers (defined in the code) against baselines or other results. It can merge multiple CSV files for comparison.

**How to Run:**
```bash
python generate_comparison_graphs.py
```

**Configuration:**  
You may need to edit the `INPUT_FILES` dictionary inside the script to point to your specific CSV files if they differ from the defaults.

**Output:**  
Saves comparison plots to the `graphs_comparison/` directory.

---

## Workflow Summary

1.  **Place Tokenizers**: Ensure your `.json` tokenizer files are in the `tokenizers/` folder.
2.  **Run Evaluation**: Execute `python evaluate_tokenizer_metrics.py` to generate the metrics CSV.
3.  **Generate Graphs**: Execute `python generate_tokenizer_graphs.py` to visualize the results.
4.  **Analyze**: Check the `graphs/` folder for the resulting images.
