# Curriculum Structure

## Difficulty Bands (B0–B5)

- **B0**: Foundational, simple content
- **B1**: Basic complexity
- **B2**: Intermediate
- **B3**: Advanced
- **B4**: Expert-level (protected)
- **B5**: Rare, capability-critical (protected)

## Domain Groups

- **Clean Web**: High-quality web text
- **Code**: Programming content
- **Math**: Mathematical reasoning
- **Reasoning**: Logical and analytical content
- **Agentic**: Task-oriented, action-taking traces
- **Indic**: Indic language content

## Protected Slices

Certain combinations are critical and must never be undersampled:

- B4/B5 content (rare but capability-critical)
- Agentic traces
- Code reasoning
- Specific domain tails

## Smooth Transitions

Stage profiles represent milestones along a continuous trajectory:

- No abrupt ratio jumps between stages
- Rolling-window constraints prevent spikes
- Gradual curriculum progression from simple → complex
