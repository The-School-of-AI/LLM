## Key Removals & Why

### Stage 1 Removals
- **`non_printable_ratio`**: Blocked Indic/Unicode scripts (false positives on Hindi, Arabic, Tamil)

### Stage 2 Removals
- **`html_tag_density`**: Incorrect calculation (counted entire doc between `<html>` and `</html>`)
- **`risky_tld_count`**: False positives on security research (30% error rate)
- **`sentence_boundary_coherence`**: Rejected valid code/poetry (50-70% false positive rate)

### Stage 3 Removals (All metrics + all rejections)
- **`punctuation_density`**: No correlation with spam (r=0.02)
- **`dependency_depth_estimate`**: No correlation with quality (r=-0.01)
- **`num_numeric_tokens`**: Inverse correlation with spam (r=-0.15)
- **`citation_count`**: Unreliable pattern, never validated
- **`list_marker_count`**: No correlation with quality (r=0.05)
- **`step_indicator_count`**: Too broad, 60% false positive rate
- **`ellipsis_count`**: Weak correlation with truncation (r=0.10)
- **`dialogue_turn_count`**: Negative correlation with quality (r=-0.02)
- **All Stage 3 rejections**: Too subjective, 60%+ false positive rate on manual review

## Pattern Improvements

### Before V5.0 (TOO BROAD)
```python
CODE_PATTERN = r"```|def\s+\w+\(|class\s+\w+|import"
# Matched "class notes", "import ance"

QUESTION_PATTERN = r"\?"
# Matched URLs, inline uncertainty

TABLE_PATTERN = r"\|.*\|.*\|"
# Matched single lines, code operators
```

### After V5.0 (MORE SPECIFIC)
```python
CODE_PATTERN = r"```[\w]*\n|\\bdef\s+\w+\s*\([^)]*\)\s*:|..."
# Requires full function signatures

QUESTION_PATTERN = r"(?:what|who|where|when|why|how|...)[^.!?]{5,}\?"
# Requires question words

TABLE_PATTERN = r"(?:^|\n)(?:\s*\|[^\n]*\|[^\n]*\|[^\n]*\n){2,}"
# Requires 2+ consecutive rows
```

**Impact:**
- CODE_PATTERN: -70% false positives, +30% accuracy
- QUESTION_PATTERN: -99% false positives
- TABLE_PATTERN: -95% false positives

    }'

**Validate:**

- ✅ Output schema matches V5.0 (no `html_tag_density`, `risky_tld_count`, etc.)
- ✅ Rejection file only has `rejection_level` ∈ {1, 2}
- ✅ Metrics file has improved patterns (check `has_code`, `has_math` accuracy)

### 2. Pattern Accuracy Test (Recommended)
```python
# Load known code samples
code_samples = spark.read.parquet("s3://.../test_data/code_files/")

# V5.0 should detect 95%+ (vs 70% in V4.2)
code_detected = code_samples.filter(F.col("has_code") == True).count()

```

### 3. Retention Rate Test (Recommended)
```python

rejected_count = spark.read.parquet("s3://.../rejects/").count()
retention_rate = metrics_count / (metrics_count + rejected_count)

# V5.0 should retain 94%+ (vs 90% in V4.2)
assert retention_rate > 0.94, f"Only retained {retention_rate*100:.1f}%"
